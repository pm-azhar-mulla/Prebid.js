Implementation

The unminified library is split into multiple files:

// Core utilities and global namespace - MUST BE LOADED FIRST
<script src="adagio_core.js"></script>

// Session and navigation management
<script src="adagio_session.js"></script>

// Browser and device features detection
<script src="adagio_features.js"></script>

// Viewability measurement functionality
<script src="adagio_measurement.js"></script>

// Main entry point and integration
<script src="adagio_main.js"></script>
